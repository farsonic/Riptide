# Riptide on the classic Mac OS: the Toolbox calls the applications use (RiptidePrefs), one line
# each, turned into C-callable glue (build/mac/app/toolbox_glue.S) and prototypes
# (build/mac/gen/toolbox_gen.h) by tools/mac_traps.py. The same names are left out of the Amiga
# prototypes the Mac build of RiptidePrefs gets (tools/gen_lvos.py, CC=proto).
#
#   trap result Name(type name:kind, ...)
#
# result and kind: l a long, p a pointer (result only), w an INTEGER, b a BOOLEAN, c a CHAR, - none (result).
# Pascal convention: room for the result, the arguments left to right, the trap word; the trap
# pops the arguments. Trap words from Inside Macintosh (Traps.a). Register-based OS traps (the
# Memory, File and Device Managers) are in ostraps.S.
# SPDX-License-Identifier: GPL-2.0-only
#
